# 署名鍵（アプリ内アップデート用）

`pianosheet-debug.keystore` は PianoSheet の **固定の debug 署名鍵**。

## なぜコミットしているか

0.4.5 でアプリ内アップデートを入れた。Android は「同じ署名鍵で署名された APK」しか
上書きインストールできないので、GitHub Actions のランナーが毎回作り直す debug 鍵
（実行ごとに別の鍵になる）でビルドすると、次の版が「アプリがインストールされていません」
で失敗する。そこで CI とローカルの両方がこのファイルで署名するようにしている
（`app/build.gradle.kts` の `signingConfigs.debug`）。

- alias: `androiddebugkey`
- store / key password: `android`（Android の標準 debug 鍵と同じ）
- 証明書 SHA-256: `5494FEBBA8E143630C69F62D240699A1410447AF5C0EA3ECA48A30BA6EDD30E`
- 有効期限: 2054-04-03

## 取り扱い

- **作り直さない。** 作り直すと、それまでに配布した APK の上にインストールできなくなり、
  利用者はアプリを一度アンインストールする必要がある（録音 WAV は `Music/PianoSheet`
  に残るが、プロジェクトと解析結果は消える）。
- このリポジトリは Public なので鍵も公開されている。インストールできるのは利用者本人が
  インストーラーを開いたときだけだが、第三者が同じ鍵で APK を作れる状態ではある。
  ストア配布に移行するときは、非公開の鍵に切り替えて一度だけ入れ直すのが良い。
- 別のマシンでビルドするときも、このファイルがあればそのまま署名できる（コピー不要）。
